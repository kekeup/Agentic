一个基于多智能体和持续学习的视频语义通信系统，支持边缘-云端协同处理、EWC持续学习和自适应模型切换。

## ✨ 核心特性

- **🤖 多智能体架构**: 边缘代理 + 云端代理协同工作
- **📊 EWC持续学习**: 防止灾难性遗忘的模型微调
- **🔧 自适应模型切换**: 基于性能监控自动切换模型
- **📈 实时监控**: SNR波动和mAP下降自动报告
- **🎯 MoE门控网络**: 动态模型选择机制
- **🚗 车辆检测**: 针对道路视频的车辆提取
